# Changelog

## 1.0.0 (2026-10-14)

First public release.

- Right-click "Force dark page" with per-site memory, global "Force dark on all sites" switch
- Two editions: CSS filter (no warning bar) and native Chrome Auto Dark Mode engine
- Toolbar button, Alt+Shift+D shortcut, ON badge
- Incognito choices kept in session storage only
- English and Italian interface
- End-to-end tests with Playwright
